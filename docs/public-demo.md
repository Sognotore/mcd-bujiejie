# 公开体验版

公网入口：https://sognotore.github.io/mcd-bujiejie/

朋友可直接打开或从微信消息点入，无需注册或安装。页面明确显示“公开体验版”和演示价格，不代表真实门店库存或售价。支持快捷及自定义预算、跳过预算、随机搭配、单品锁定、重抽和复制清单。

## 发布结构

- GitHub Pages 来源为本仓库 `codex/wechat-demo` 分支根目录，强制 HTTPS。
- `npm run build:pages` 只构建 白名单网页文件和 11 张生成示意图，不包含服务器、依赖、`.env`、`.local` 或账户响应。
- 公开页面在浏览器内使用同一搭配引擎和演示数据；不提供作者 MCP 账户的共享代理。
- 本机实时模式保留原有门店、菜单及官方最终价格试算流程。

更新时先执行 `npm run build:pages`、`npm run check:pages`，将 `dist/` 中的 白名单静态文件及 assets/ 目录同步到发布分支后提交并正常推送。不要把项目根目录或账户文件复制到发布分支。
