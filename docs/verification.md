## 独立代码审查与修复

独立审查覆盖完整提交范围，并实跑业务测试。发现的规格锁定、长连接 schema 失效和套餐复制关系问题均已建立失败回归用例后修复，完整业务和浏览器测试重新通过。

- 锁定 ID 由实际规格、数量及默认特调参数的稳定快照生成；配置变化后旧锁定报不可用，不静默替换。网页与 Skill 共用该快照实现。
- 每次新的选店/推荐/计价事务强制核验 schema，普通工具调用最长复用 5 秒；官方工具列表通知会清除旧校验，调用中收到变化也需复核后才接受返回。没有宣称能发现服务器未通知且尚处校验窗口内的一切变化。
- 套餐复制文本包含父套餐名称、1 份套餐及明确的套餐内组成，避免把套餐错当三个独立单品。
- 未保留未处理的 Critical/Important 或刻意延后的 Minor。

审查中未联网判断的官方字段、视觉、声明和报名状态，由主执行者分别以真实接口、浏览器截图、原文件字节核对及平台回执核验；没有扩大为全门店、全客户端或获奖保证。

修复后额外完成真实重抽：锁定同一饮品的精确配置，返回不同搭配且应付仍在 50 元预算内；证据仅在本机 `.local/live-lock-proof.json` 保留。
